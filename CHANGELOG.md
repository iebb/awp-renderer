# Changelog

## 0.1.0 — 2026-10-25

- Standalone ESM/TypeScript package with separate core, React, and server exports.
- JSON/assets → lossless ZIP → native Apple preview, exact source required by default.
- React component and hook with debounce, cancellation, independent instances, and stale-result protection.
- `awp-renderer serve`, `render`, and `doctor` commands.
- Local JSON playground with six synthetic examples, phone/Watch faces, artwork upload, text stress cases, PNG export, and layout export.
- Bounded input, token authentication, origin checks, and explicit approximate rendering opt-in.
- Independent pixel comparisons, portable tests, and clean-consumer package checks.
